# OpenLadder

Free, open-source PLC ladder logic simulator. Runs in any browser, works on phones. No locks, no ads, no account.

## Features
- Contacts: NO, NC, rising edge, falling edge, with parallel OR branches
- Outputs: OUT, SET, RST, TON, TOF, CTU, RES
- Live power flow, input switches (toggle or momentary), output lamps
- Examples, export/import of programs as JSON, autosave in the browser

## Use
Open `index.html`, or host it free with GitHub Pages (Settings > Pages > deploy from `main` branch, root).
